## 📝 Tổng quan dự án
Repository này chứa bài làm cho Phiếu bài tập 04, tập trung vào việc xây dựng và quản lý bố cục (layout) trang web sử dụng CSS. Dự án áp dụng thực tế các thuộc tính từ cơ bản đến nâng cao như 5 loại Positioning (static, relative, absolute, fixed, sticky), hệ thống bố cục một chiều linh hoạt (Flexbox), và hệ thống lưới hai chiều phức tạp (CSS Grid).
