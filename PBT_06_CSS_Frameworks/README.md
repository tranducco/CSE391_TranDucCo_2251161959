## 📝 Tổng quan dự án
Repository này chứa bài làm cho Phiếu bài tập 06, Track A. Dự án tập trung vào việc sử dụng framework **Bootstrap 5** để xây dựng giao diện web Responsive một cách nhanh chóng mà không cần viết CSS thuần.
